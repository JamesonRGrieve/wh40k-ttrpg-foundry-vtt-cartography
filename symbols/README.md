# Canonical Symbol Library

The cartography pipeline does NOT trust diffusion to render Imperial
iconography. Aquila feathers/heads/swords drift; Inquisition `I`s
become generic crosses; Mechanicus cog teeth multiply. This library
holds **canonical PNG masters** that downstream generators paste onto
diffusion output.

## Layout

Each symbol lives in its own folder:

```
symbols/<name>/
├── canonical.png          # transparent-bg master, single source of truth
├── canonical_dim.png      # optional lighting variant
├── canonical_lit.png      # optional lighting variant
├── canonical_red.png      # optional red-emergency variant
└── metadata.json          # anchor scale, allowed rotations, mirror policy
```

`canonical.png` MUST be a transparent-background PNG. Square aspect
ratios are preferred; non-square is allowed when the symbol's natural
shape demands it (e.g. a banner is taller than wide).

## metadata.json schema

```json
{
  "name": "aquila",
  "display_name": "Imperial Aquila",
  "default_size_px": 256,
  "allowed_rotations": [0, 90, 180, 270],
  "allowed_mirror": false,
  "preserve_aspect": true,
  "anchor_hints": ["chapel_apse_back", "robe_chest", "banner_field"],
  "validation": {
    "method": "canny_iou",
    "threshold": 0.85
  }
}
```

| Field | Purpose |
| --- | --- |
| `name` | Folder name; used as the wikilink-equivalent ID. |
| `display_name` | Operator-facing label. |
| `default_size_px` | Default render size in the asset; pipelines may override per anchor. |
| `allowed_rotations` | Subset of {0,90,180,270}; never freely rotated, only stepped. |
| `allowed_mirror` | If true, may horizontal-flip (e.g. a flame); if false (Aquila), never mirror. |
| `preserve_aspect` | If true, scale uniformly; if false, may stretch (banners). |
| `anchor_hints` | Free-form strings declaring legal anchor names that downstream pipelines understand. |
| `validation.method` | `canny_iou` is the default — Canny edges of the composited region vs canonical, intersection-over-union. |
| `validation.threshold` | Below this, the composite is flagged for operator review. |

## Sourcing canonical art

These symbols are Games Workshop intellectual property. The campaign
is operating under personal-use fair use. **The operator must source
or approve every canonical**:

1. **Operator-provided.** Best path. Drop a clean transparent-PNG
   master into `symbols/<name>/canonical.png` and write metadata.
2. **Diffusion-generated then locked.** Use a one-off Flux render
   with strong negative prompts to produce a clean candidate, hand-
   review for fidelity, and lock as canonical. Once locked, the
   PNG is never regenerated by automated pipelines — only manually
   replaced.
3. **External CC0 reference.** Fan-art under CC0 may exist; vet
   carefully. Prefer (1) or (2).

Until a canonical exists for a symbol, all generators that would
need it MUST refuse to render rather than fall back to "Flux draws
the symbol." This is enforced in `symbol_compose.py`.

## Hard rules

1. **No silent fallback.** If `canonical.png` is missing, fail loud.
2. **No automated overwrite.** A canonical in this directory is
   the result of operator review. Pipelines never write to
   `symbols/`. The validator is read-only.
3. **No diffusion of canonical regions.** Generators must include
   anti-symbol negative prompts (e.g. "no Imperial Aquila in the
   render — composited separately") so Flux doesn't paint the
   symbol underneath where we'll paste over it.
4. **Aspect / rotation / mirror policy is metadata-driven.** Don't
   freely transform a canonical without consulting `metadata.json`.

## Adding a new symbol

1. Create `symbols/<new_name>/`.
2. Drop in `canonical.png` (transparent-bg).
3. Write `metadata.json` from the schema above.
4. Run `uv run symbol_compose.py validate <new_name>` — sanity
   checks the PNG (transparent? square? readable?) and the JSON
   (parseable? all required fields?).
5. Add an anchor entry in any pipeline template that should use it.
